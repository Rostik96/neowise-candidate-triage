# Тестовое Neowise. AI-помощник для входящих заявок

Менеджер вводит текст заявки, получает тему и черновик ответа. Он читает результат и сам решает, что отправить клиенту.

Нужен Node.js 20 или новее. Зависимостей и ключей нет.

## Запуск

```sh
node server.mjs
```

Откройте http://127.0.0.1:3000. Порт можно задать через переменную `PORT`.

## Тесты

```sh
node --test
```

Проверяется пустой и некорректный ввод, таймаут модели (ожидание не дольше 300 мс), ошибка модели, некорректный ответ и обычная заявка.

## Поведение

`POST /api/triage` принимает JSON с полем `text` — непустой строкой.

- Пустой, отсутствующий, нестроковый ввод или битый JSON — HTTP 400 и `{"status":"invalid_input"}`.
- Корректный ответ модели — HTTP 200 и `{"status":"ready","topic":"…","draft":"…"}`. Темы: `delivery`, `pricing`, `other`. Черновик — непустая строка.
- Таймаут, ошибка модели или неподходящий ответ — HTTP 200 и `{"status":"manual_review","topic":null,"draft":null}`. Ожидание модели ограничено 300 мс.

На странице при успехе видны тема и черновик. При ручном разборе показывается сообщение менеджеру, а предыдущий черновик очищается.

Имитатор принимает любой обычный текст. Метки `[timeout]`, `[error]`, `[bad-json]`, `[bad-topic]`, `[empty-draft]` включают отдельные сценарии сбоя. Поведение имитатора не менялось.

## Польза для менеджера

Менеджер сразу видит тему заявки и черновик ответа и тратит время на проверку, а не на текст с нуля; пользу можно измерить долей заявок со статусом ready и средним временем до отправки ответа клиенту.
